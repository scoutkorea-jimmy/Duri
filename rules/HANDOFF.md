# HANDOFF — 진행 중 작업 (가장 먼저 읽는 문서)

> **⛔ 이 저장소에서 일을 시작할 때 가장 먼저 여는 문서입니다.**
> 지시를 받으면 **코드를 건드리기 전에 이 파일에 먼저 작업을 등록**하고, 진행하면서 갱신합니다.
> 완료된 작업의 결과·사유는 [WORKLOG.md](WORKLOG.md)로 옮깁니다. 규칙 인덱스는 [README.md](README.md).

---

## 이 문서의 규칙

**HANDOFF = 지금 진행 중인 것 / WORKLOG = 끝난 것.** 역할을 섞지 마세요.

1. **지시를 받은 즉시**, 아직 아무것도 조사·수정하기 전에 아래 "진행 중" 에 항목을 만듭니다.
   지시 원문, 목표, 성공 판단 기준을 먼저 적습니다. **비어 있는 항목이라도 만드는 것이 규칙입니다.**
2. 작업하면서 **"어디까지 됐는지"를 계속 갱신**합니다. 다음 세션이 맥락 없이 읽어도 이어받을 수 있어야 합니다.
3. 작업이 끝나면
   - [WORKLOG.md](WORKLOG.md)에 결과 + **성공 사유 / 실패 사유**를 기록하고
   - 이 문서의 항목을 **"최근 종료"** 로 옮깁니다(3건까지만 남기고 그 이상은 지웁니다).
4. 막히면 항목 상태를 `⏸ 보류`로 바꾸고 **무엇이 막았는지, 무엇이 있으면 풀리는지**를 적습니다.
   보류된 항목은 지우지 않습니다.
5. 사용자가 위험을 고지받고도 진행을 지시했다면 해당 항목에 **리스크 감수 기록**을 남깁니다.

### 항목 틀

```markdown
### [상태] 한 줄 제목
- **지시**: 사용자 원문(요지)
- **목표 / 성공 기준**: 무엇이 되면 끝인가
- **진행**:
  - [x] 끝난 단계
  - [ ] ← 지금 여기. 구체적으로
- **다음 한 수**: 복사해 실행할 수 있는 형태로
- **건드린 것**: 경로 / 한 일 / 되돌리는 법
- **막힌 것 · 확인 필요**: 사용자에게 물어야 할 것
```

상태: `▶ 진행 중` · `⏸ 보류` · `✅ 종료(WORKLOG 기록 완료)`

## 1. 메뉴 (헤더 · 메가드롭다운 · 모바일 메뉴)

`duri-website/assets/site.js`의 배열 **한 곳만** 고칩니다. 전 페이지에 자동 반영됩니다.

```js
const NAV = [
  { label:"두리손잡고 소개", href:"about.html", sub:[
    ["인사말","about.html"], ["운영현황","operation.html"], ...
  ]},
  ...
];
```

- `label` — 상단 메뉴 이름. **줄바꿈되지 않도록 짧게**(`white-space:nowrap`이 걸려 있음).
- `href` — 상단 메뉴 클릭 시 이동할 페이지. 현재 페이지와 같으면 `.active`가 자동으로 붙습니다.
- `sub` — `[표시명, 링크]` 쌍의 배열. 메가드롭다운과 모바일 메뉴에 동시 사용됩니다.
- 앵커 링크(`operation.html#location`)도 그대로 쓸 수 있습니다.
- **직업재활센터 메뉴는 `NAV_REHAB` 배열**입니다. 현재 비어 있고(준비중), 채우면 `rehab` 갈래 페이지에 메뉴가 나타납니다.

⚠️ 항목을 5개 넘게 늘리면 데스크탑 헤더가 좁아집니다. 반응형 분기(1260px)를 함께 확인하세요 → [40-verify.md](40-verify.md)

## 2. 공지사항 글

| 상황 | 방법 |
|---|---|
| **모든 방문자에게 보여야 하는 공지** | `assets/board.js`의 `SEED` 배열에 항목 추가 후 커밋·배포 |
| 임시로 화면에서 써보는 글 | 관리자 로그인 → 공지사항 페이지 "글쓰기". **그 브라우저에만 저장됨** |

`SEED` 항목 형식:

```js
{ id:"s25", cat:"공지", pinned:true, date:"2026.08.17",
  title:"제목",
  body:"본문.\n\n· 줄바꿈은 \\n 으로.\n· 상세 모달에서 그대로 표시됩니다." }
```

- `id` — 시드 글은 **반드시 `s`로 시작**(사용자 글 `u*`와 구분되며, `s*`는 화면에서 삭제 불가).
- `cat` — `공지` / `새소식` / `언론보도` 셋 중 하나. 다른 값을 넣으면 탭 필터에서 사라집니다.
- `pinned` — `true`면 목록 최상단 고정 + 번호 자리에 확성기 아이콘.
- `date` — **`YYYY.MM.DD` 형식 고정.** 문자열 비교로 정렬하므로 형식이 다르면 순서가 틀어집니다.

## 3. 사진 갤러리

`gallery.html`의 `.masonry` 안에 타일을 추가합니다.

```html
<div class="tile" data-cat="행사">
  <div class="ph g3"></div>
  <div class="cap">사진 설명</div>
  <div class="yr">2026</div>
</div>
```

- `data-cat` 값은 상단 `.filter-row` 버튼의 **텍스트와 정확히 일치**해야 필터가 동작합니다.
- `.ph`의 `g1`~`g5`는 그라데이션 플레이스홀더. 실제 사진으로 교체할 때는 `.ph` 자리에 `<img>`를 넣고 **`alt`를 반드시 작성**합니다.

## 4. 파트너 로고 마퀴 (index.html)

`index.html` 하단 스크립트의 `PARTNERS` 배열에 추가합니다.

```js
var PARTNERS = [
  { name:"고려홍삼" },                                  // 로고 없으면 이름 텍스트로 표시
  { name:"NH 농협", logo:"assets/logos/nh.png" }        // logo 경로가 있으면 <img>로 자동 표시
];
```

- 이미지는 `duri-website/assets/logos/`에 넣습니다(폴더가 없으면 생성).
- 배경 투명 PNG 또는 SVG 권장. 기본 grayscale로 표시되고 hover 시 컬러로 돌아옵니다.
- 항목은 렌더 시 랜덤 셔플 후 2배 복제되어 이음새 없이 무한 스크롤합니다. **항목을 지울 때 복제 로직을 건드리지 마세요.**
